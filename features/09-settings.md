# Feature: Settings

## 목적

사용자가 자기 데이터, 알림, 프라이버시를 직접 통제할 수 있게 함. **빚 데이터는 매우 민감하므로 컨트롤 권한이 명확히 사용자에게 있어야 함**.

## 우선순위

**Phase 1에 일부 필수, 나머지 Phase 2-4 분산**

### Phase 1 (출시 필수)
- 프로필 (닉네임만)
- 알림 ON/OFF
- 로그아웃
- 회원 탈퇴

### Phase 2
- 상환 전략 변경
- 알림 세부 설정
- 데이터 내보내기
- 차단 사용자 관리 (커뮤니티 출시와 함께)

### Phase 3-4
- 앱 잠금 (생체인증)
- 금액 가리기 모드
- 다크모드
- 데이터 동기화 옵션

## 사용자 스토리

> 내 데이터와 알림을 내가 컨트롤하고, 더 이상 쓰지 않게 되면 깔끔하게 떠날 수 있어야 한다.

## 진입 경로

- 하단 탭바의 "설정" 또는 대시보드 우상단 톱니바퀴

## 화면 1: 설정 메인

### 헤더
- "설정"

### 섹션 1: 프로필
- 카드 또는 리스트 셀
- 좌측: 아바타 (이니셜 또는 이미지)
- 우측: 닉네임 + 이메일 (가려진)
- 탭하면 프로필 화면

### 섹션 2: 빚 관리
- **상환 전략** (현재 값 표시: "눈덩이 방식")
- **빚 목록 정리** (졸업한 빚 보기/숨기기)
- **데이터 내보내기**

### 섹션 3: 알림
- **알림 설정** (전체 ON/OFF)
- 탭하면 세부 설정 화면

### 섹션 4: 프라이버시
- **앱 잠금** (Face ID / 지문)
- **금액 가리기 모드**
- **차단 사용자 관리**

### 섹션 5: 화면
- **테마** (Phase 4 이후): 라이트 / 다크 / 시스템 따라가기

### 섹션 6: 정보
- **버전** (예: "1.0.3")
- **이용약관**
- **개인정보처리방침**
- **고객센터** (이메일 또는 외부 링크)

### 섹션 7: 계정
- **로그아웃** (보더 버튼)
- **회원 탈퇴** (텍스트 링크, 빨간색)

## 화면 2: 프로필

### 닉네임 변경
- 현재 닉네임 표시
- 변경 버튼
- **30일에 1회 제한** 안내
- 마지막 변경일 표시 ("지난 변경: 2025년 4월 1일")
- 변경 시 자동 추천 5개 + 직접 입력 옵션

### 이메일
- 표시만 (변경은 Phase 4)

### 가입일
- 표시만

### 가입 방식
- "카카오로 가입" 등 표시

## 화면 3: 상환 전략 (Phase 2)

`05-simulation.md`와 동일한 화면을 별도 진입 경로로 활용. 또는 단순 선택 화면:

- **눈덩이 방식 (Snowball)** + 설명
- **눈사태 방식 (Avalanche)** + 설명
- 라디오 단일 선택
- 적용 시 우선순위 자동 재계산
- 토스트: "전략이 변경됐어요. 새 우선순위로 정렬됐어요."

## 화면 4: 알림 세부 설정

### 전체 ON/OFF (마스터 스위치)
- 끄면 아래 모든 알림 비활성

### 결제일 알림
- 토글 ON/OFF
- 시점 선택 (라디오):
  - 3일 전 (디폴트)
  - 당일 아침 9시
- 빚별 개별 설정은 빚 상세 화면에서 (이건 전역 디폴트)

### 동기부여 알림
- 토글 ON/OFF (디폴트 OFF)
- 시간 선택 (시간 picker, 디폴트 9:00)

### 연속 기록 위험 알림
- 토글 ON/OFF (디폴트 ON)
- 자동 시점: 밤 9시 (사용자 시간대)

### 커뮤니티 반응 알림 (Phase 3 이후)
- 토글 ON/OFF
- 세부:
  - 댓글
  - 답글
  - 좋아요 (디폴트 OFF, 스팸 방지)

## 화면 5: 프라이버시

### 앱 잠금 (Phase 3+)
- 토글 ON/OFF
- ON 시:
  - Face ID / Touch ID / 패턴 / PIN 중 선택
  - 디바이스 지원 따라 옵션 다름
  - 잠금 시점: "즉시" / "1분 후" / "5분 후"

### 금액 가리기 모드 (Phase 3+)
- 토글 ON/OFF
- ON 시:
  - 모든 금액이 "●●●,●●●원"으로 표시
  - 빚 카드 길게 누르면 잠시 표시
  - 카페 등 공공장소에서 유용

### 차단 사용자 관리
- 차단한 사용자 리스트
- 각 항목에 "차단 해제" 버튼

## 화면 6: 데이터 내보내기

### 형식
- CSV (빚, 상환 기록)
- JSON (전체 데이터)

### 내보낼 항목 (체크박스)
- 빚 목록
- 상환 기록
- 배지
- 통계 데이터

### 액션
- "내보내기" 버튼
- 파일 생성 후 공유 시트 (이메일, 클라우드 등)

### 사용 사례
- 백업
- 가계부 앱 이동
- 세무 신고 자료

## 회원 탈퇴 흐름 (중요)

### Step 1: 경고 화면
- "정말 떠나시려고요?"
- 떠나면 잃는 것 안내:
  - 지금까지 갚은 X원의 기록
  - 연속 기록 X일
  - 획득한 배지 X개
  - 등록한 빚 데이터
- 시각적으로 진지하게

### Step 2: 사유 선택 (선택, 분석용)
- "잠시 시간 내주실 수 있나요?"
- 라디오:
  - 더 이상 빚이 없어요 (졸업)
  - 다른 앱으로 이동
  - 너무 자주 알림이 와요
  - 사용법이 어려워요
  - 기타
- "넘기기" 버튼도 제공

### Step 3: 최종 확인
- 비밀번호 또는 본인 확인
- "회원 탈퇴" 버튼 (빨강)
- "취소" 버튼 (메인)

### Step 4: 30일 유예 안내 (권장)
- "30일 동안 데이터를 보관해요. 마음이 바뀌면 다시 로그인하세요."
- 30일 후 영구 삭제
- Phase 1에서는 즉시 삭제도 OK (단, 명시적 안내)

### 탈퇴 후
- 자동 로그아웃
- 온보딩 화면으로
- 같은 이메일로 재가입 가능

## 로그아웃 흐름

### 단순 흐름
- 다이얼로그: "로그아웃하시겠어요?"
- 확인 버튼

### 처리
- 토큰 삭제 (`flutter_secure_storage`)
- 최근 로그인 카드 정보도 삭제
- 로그인 화면으로 이동
- 단, **로컬 빚 데이터는 보존** (다시 로그인하면 복구)

## 카피 디테일

### 톤
- 정중함 + 친근함
- 부정적 액션(탈퇴, 로그아웃)도 비난 X
- 데이터 통제권은 사용자에게

### 회원 탈퇴 카피
- "정말 떠나시려고요?" (감정적 어필 OK, 단 과하지 않게)
- "지금까지의 여정" 회상 (인지적 관성 활용)
- "30일 안에 마음 바꿀 수 있어요" (안심)

### 알림 OFF 카피
- "알림을 꺼도 다시 켤 수 있어요"
- 위협적이지 않게

## Edge Cases

### 닉네임 30일 제한 우회 시도
- "30일 후 변경할 수 있어요. 다음 변경 가능일: 5월 15일"

### 이메일 사용자가 자기 비밀번호 잊은 채 탈퇴 시도
- 비밀번호 찾기 흐름으로 유도
- 또는 이메일 인증으로 대체 가능

### 소셜 로그인 사용자 탈퇴
- 비밀번호 확인 단계 생략 (또는 "본인 확인" 메시지로 카카오 재인증)
- Apple 사용자: Apple Sign In 재인증

### 활성 빚이 있는 사용자 탈퇴
- 추가 경고: "갚지 못한 빚이 X개 있어요. 다른 곳에서 추적할 계획인가요?"
- 단, 막지는 않음 (사용자 자유)

### 30일 유예 중 재로그인
- "다시 돌아오셨네요!" 환영
- 모든 데이터 복구
- 탈퇴 취소

### 알림 권한 시스템 거부
- 사용자가 OS 레벨에서 알림 거부한 경우
- 앱 내 토글 의미 없음
- "OS 설정에서 알림을 켜주세요" 안내 + 설정 앱 딥링크

### 데이터 내보내기 실패
- 네트워크 필요 없음 (로컬 데이터)
- 권한 문제 시 "파일 저장 권한이 필요해요"

### 차단 사용자가 닉네임 변경
- 차단은 user_id 기반이라 무관
- 닉네임 변경해도 여전히 차단 상태

## 분석 이벤트

- `settings_viewed`
- `settings_section_opened` (sectionId)
- `settings_strategy_changed` (oldStrategy, newStrategy)
- `settings_notification_toggled` (type, enabled)
- `settings_app_lock_enabled` / `disabled`
- `settings_data_exported` (formats, scopes)
- `settings_logout`
- `settings_account_delete_started`
- `settings_account_delete_canceled`
- `settings_account_delete_completed` (reason)

## 보안

### 민감한 작업 보호
- 회원 탈퇴: 비밀번호 또는 재인증 필수
- 데이터 내보내기: 앱 잠금 ON 시 인증 요구
- 닉네임 변경: 일반 보호 (특별 인증 불필요)

### 민감 데이터
- 이메일은 마스킹 표시 (jisu***@email.com)
- 토큰은 절대 UI 노출 X
