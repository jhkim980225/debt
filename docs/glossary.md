# Glossary

앱 전반에서 사용하는 용어 정의. 일관성을 위해 이 목록 외 표현 사용 금지.

## 사용자 노출 용어 (UI)

### 빚 관련
| 권장 | 비권장 | 이유 |
|------|--------|------|
| 빚 | 부채 | 일상적 표현 |
| 갚다, 상환하다 | 변제하다 | 친근함 |
| 잔액 | 잔여 채무 | 단순함 |
| 이자율 | 금리 | 명확함 |
| 졸업 | 완납 | 긍정적 |
| 우선순위 빚 | 제1 채무 | 친근함 |

### 진전 관련
| 권장 | 비권장 |
|------|--------|
| 진행률 | 달성도 |
| 연속 기록 | 출석 |
| 배지 | 업적, 트로피 |
| 한 걸음 | 한 단계 |

### 카테고리

|-----------|---------|

## 카피 톤 가이드

### 좋은 예 ✓
- "오늘도 한 걸음씩, 천천히 가요"
- "잘하고 있어요. 이 페이스면 8개월 안에..."
- "함께 갚아봐요"
- "정확하지 않아도 괜찮아요"

### 나쁜 예 ✗
- "당신은 빚이 너무 많습니다"
- "더 열심히 갚으세요"
- "계획대로 안 되고 있습니다"
- "경고: 결제일이 다가옵니다"

## 금액 포맷

- 원 단위까지: `1,234,567원`
- 만원 단위 표시: `1,234만원`
- 범위 표시 (커뮤니티): `1000만원대` (1,000~9,999만원)
- 음수 표시 안 함, 변화량은 `▼ 850,000원` 또는 `▲ 5%`

## 날짜 포맷

- 절대 날짜: `2025년 5월 1일` 또는 `5월 1일` (당해)
- 상대 날짜: `방금 전`, `5분 전`, `2시간 전`, `어제`, `2일 전`, `3월 15일` (1주일 이상)
- 시간: `14:32` (24시간제)

## 닉네임 시스템

- **자동 생성 패턴**: `[형용사/자연] + [동사/명사]`
- 예시:
  - 햇살모은이, 조용한걸음, 바람부는언덕
  - 새벽두시, 천천히가는, 노을지는하늘
  - 작은별빛, 따뜻한봄날, 푸른산책로
- 가입 시 5개 후보 제시, 사용자가 선택 또는 새로고침
- 본인이 직접 짓고 싶으면 그 옵션도 제공 (단, 욕설/실명 금지)

## 배지 이름 규칙

- 짧고 시각적: "첫 걸음", "100일 연속", "1000만원"
- 비교형 금지: "최고", "1등"
- 부정형 금지: "포기 안 함"
- 긍정/중립만: "꾸준함", "한 걸음 더"

## 알림 메시지 톤

- 명령형 X: "갚으세요"
- 친구처럼 ○: "오늘 5만원 어때요?"
- 압박 X: "빚이 늘어나고 있습니다"
- 격려 ○: "어제까지 6일째예요. 오늘이 7일째!"

## 기술 용어 (개발자/PR용)

| 용어 | 설명 |
|------|------|
| Snowball | 작은 빚부터 갚는 전략 |
| Avalanche | 고이자 빚부터 갚는 전략 |
| Streak | 연속 기록 |
| Badge | 배지 |
| Graduate / Paid Off | 빚 완납 |
| Priority Debt | 우선순위 빚 (전략 기반) |
| Min Payment | 최소 상환액 (카드사가 요구하는) |
| Target Payment | 목표 상환액 (사용자가 정한) |
