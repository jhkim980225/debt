# Feature: Authentication

## 목적

사용자가 빠르고 안전하게 가입/로그인할 수 있게 함. 빚 데이터는 민감하므로 보안과 편의성 균형이 중요.

## 우선순위

**Phase 1 (출시 필수)**

## 핵심 원칙

1. **소셜 로그인 우선**: 한국 시장 기준 가입 마찰 최소화
2. **이메일은 보조**: 소셜 안 쓰는 사용자를 위함
3. **카카오가 1번**: 한국 사용자 대다수가 쓰는 플랫폼
4. **Apple 필수**: 다른 소셜 있으면 iOS 앱스토어 정책상 필수
5. **자동 로그인 디폴트 on**: 매일 쓰는 앱이라 매번 로그인은 마찰

## 화면 목록

1. 회원가입 화면
2. 로그인 화면
3. 비밀번호 찾기 (3단계)
4. 이메일 회원가입 (소셜 외 선택 시)

## 1. 회원가입 화면

### 레이아웃
- 헤더: 뒤로가기 화살표만 (앱바 제목 없음)
- 메인 영역:
  - 헤드라인: "시작하기"
  - 서브: "3초만에 가입하고 빚 관리를 시작하세요"
- 소셜 로그인 버튼 4개 (세로 스택)
  - 카카오 (노랑 #FEE500)
  - Google (흰 배경, 회색 보더)
  - Apple (검정)
  - 네이버 (녹색 #03C75A)
- 구분선: "또는"
- 이메일 회원가입 버튼 (보조 스타일)
- 하단: 약관 동의 안내 텍스트
- 최하단: "이미 계정이 있나요? 로그인"

### 약관 동의 처리
- **암시적 동의**: "가입하면 ~약관에 동의하는 것으로 간주" 텍스트로
- 약관/개인정보 처리방침 링크는 그 텍스트 안에서 별도 페이지로
- **주의**: 한국 개인정보보호법상 명시적 동의 필요한 경우 있음. 변호사 검토 후 결정.

### 인터랙션
- 소셜 버튼 탭 → 해당 OAuth 플로우 → 성공 시 빚 등록 화면 진입
- 이메일 버튼 → 이메일 회원가입 화면
- "로그인" 텍스트 → 로그인 화면

## 2. 로그인 화면

### 레이아웃
- 헤더: 뒤로가기
- 메인:
  - 헤드라인: "다시 만나서 반가워요"
  - 서브: "계속 이어서 갚아볼까요?"
- **최근 로그인 카드** (있을 때만 표시)
  - 마지막 로그인 사용자 이메일 + 사용한 인증 방식
  - 한 번 탭으로 자동 로그인
- 이메일/비밀번호 입력
  - 이메일 필드
  - 비밀번호 필드 (눈 아이콘으로 표시 토글)
- "자동 로그인" 체크박스 + "비밀번호 찾기" 링크
- 메인 로그인 버튼
- 구분선: "간편 로그인"
- 소셜 로그인 동그란 아이콘 4개 (회원가입과 동일 순서)
- 하단: "아직 계정이 없나요? 회원가입"

### 최근 로그인 카드 (중요)
- **로직**: 마지막 성공 로그인 시 사용자 이메일 + 인증 방식을 `flutter_secure_storage`에 저장
- **표시**: 같은 기기에서 다시 열면 카드로 표시
- **탭**: 한 번 탭으로 그 방식으로 자동 로그인 시도
- **삭제**: 명시적 로그아웃 시 삭제

### 자동 로그인
- 디폴트 ON
- 토큰을 `flutter_secure_storage`에 보관
- 토큰 만료 시 자동 갱신 시도, 실패 시 로그인 화면

## 3. 비밀번호 찾기 (3단계)

이메일 회원가입한 사용자만 사용. 소셜 가입자는 해당 플랫폼에서 처리.

### Step 1: 이메일 입력
- 헤드라인: "비밀번호를 잊으셨나요?"
- 서브: "가입하신 이메일 주소를 입력해주세요. 인증 코드를 보내드릴게요."
- 이메일 입력칸
- **안내 박스**: "소셜 로그인(카카오, 구글 등)으로 가입하셨다면 해당 서비스에서 직접 로그인해주세요."
- 메인 버튼: "인증 코드 받기"
- 진행률: 1/3 (33%)

### Step 2: 인증 코드 입력
- 헤드라인: "인증 코드를 입력하세요"
- 서브: "{email}으로 6자리 코드를 보냈어요."
- 6칸 인증 코드 입력 (자동 다음 칸 이동)
- 남은 시간 카운트다운 (3분, mm:ss)
- "코드 재발송" 버튼
- "메일이 안 와요" 토글 (펼치면 스팸함 안내 등)
- 메인 버튼: "확인"
- 진행률: 2/3 (66%)

#### 코드 정책
- 6자리 숫자
- 유효 시간: 3분
- 재발송 쿨다운: 1분
- 최대 시도: 5회 (초과 시 잠금 10분)

### Step 3: 새 비밀번호 설정
- 헤드라인: "새 비밀번호 설정"
- 서브: "8자 이상, 영문·숫자·특수문자 포함"
- 새 비밀번호 입력 + 표시 토글
- **강도 표시 바**: 4칸짜리, 실시간 평가
  - 약함 (1칸): 8자 이하
  - 보통 (2칸): 영문+숫자
  - 강함 (3칸): + 특수문자
  - 매우 강함 (4칸): + 12자 이상 또는 대소문자 혼합
- 비밀번호 확인 입력 (일치하면 ✓ 표시)
- **요구사항 체크리스트** (실시간 ✓ 표시):
  - 8자 이상
  - 영문 포함
  - 숫자 포함
  - 특수문자 포함
- 메인 버튼: "비밀번호 변경하기"
- 진행률: 3/3 (100%, 녹색)

#### 변경 후
- 성공 토스트: "비밀번호가 변경됐어요"
- 자동 로그인 → 대시보드

## 4. 이메일 회원가입

회원가입 화면에서 "이메일로 가입하기" 선택 시.

### 입력 항목
- 이메일 (검증: 형식, 중복 체크)
- 비밀번호 (강도 체크, 비번 찾기 화면과 동일 정책)
- 비밀번호 확인
- 닉네임 자동 생성 (5개 후보 중 선택, "다른 추천" 버튼)

### 가입 후 흐름
- 이메일 인증 메일 발송 (선택, Phase 2 도입 가능)
- 빚 등록 1단계로 자동 이동

## 사용자 흐름

### 신규 가입 (소셜)
```
온보딩 마지막 → 회원가입 화면
→ 카카오 버튼 탭 → 카카오 OAuth → 권한 동의
→ 서버에 사용자 생성 → JWT 발급
→ 빚 등록 1단계 (강제, 건너뛰기 X)
```

### 기존 회원 로그인 (자동)
```
앱 실행 → 스플래시 → 토큰 검증 → 대시보드
```

### 기존 회원 로그인 (수동)
```
앱 실행 → 스플래시 → 토큰 없음 → 온보딩 → 회원가입 화면
→ "로그인" 링크 → 로그인 화면 → 최근 로그인 카드 탭
→ OAuth → 대시보드
```

## 보안 요구사항

### 토큰 관리
- 액세스 토큰: 메모리 + `flutter_secure_storage`
- 리프레시 토큰: `flutter_secure_storage`만
- 만료 시간: 액세스 1시간, 리프레시 30일
- 자동 갱신: 액세스 만료 5분 전 백그라운드에서

### 비밀번호 정책
- 최소 8자
- 영문 + 숫자 + 특수문자 필수 (3종)
- 최대 길이: 64자
- 일반적인 비밀번호 차단 (예: `12345678`, `password`)
- 클라이언트에서 hash 안 함, 평문으로 HTTPS 전송 → 서버에서 bcrypt

### 소셜 로그인 보안
- OAuth 2.0 표준 준수
- State 파라미터로 CSRF 방지
- 카카오는 Kakao SDK 사용 (네이티브)
- Apple Sign In은 Apple SDK 사용 (iOS)

### Rate Limiting (서버 측)
- 로그인 실패: 5회/15분 시 IP 잠금
- 비번 찾기 코드 발송: 3회/시간
- 회원가입: 5회/일 같은 IP

## 에러 처리

### 사용자 노출 메시지
| 상황 | 메시지 |
|------|--------|
| 잘못된 비밀번호 | "이메일 또는 비밀번호를 확인해주세요" (보안상 어느 게 틀렸는지 안 알림) |
| 가입 안 된 이메일 | "이메일 또는 비밀번호를 확인해주세요" |
| 중복 이메일 | "이미 가입된 이메일이에요. 로그인해주세요" |
| 잠금 상태 | "잠시 후 다시 시도해주세요" |
| 네트워크 에러 | "인터넷 연결을 확인해주세요" |
| 소셜 로그인 취소 | (메시지 없이 그냥 화면 유지) |
| 인증 코드 만료 | "코드가 만료됐어요. 다시 받아주세요" |
| 인증 코드 틀림 | "코드가 일치하지 않아요" |

## Edge Cases

### 같은 이메일로 다른 소셜 가입 시도
- 시나리오: 카카오로 가입한 jisu@email.com이 구글로 다시 로그인 시도
- **처리**: 서버에서 이메일 매칭 → "이미 카카오로 가입된 이메일이에요. 카카오로 로그인해주세요" 안내

### 토큰 만료 + 오프라인
- 액세스 토큰 만료, 리프레시 시도 실패 (네트워크 끊김)
- **처리**: 캐시된 데이터로 읽기 모드만 허용. 쓰기 시도 시 "온라인이 필요해요" 안내.

### 비밀번호 찾기 - 이메일 미수신
- 3분 안에 도착 안 하면?
- **처리**: 카운트다운 끝나면 "코드 재발송" 강조. "메일 안 와요" 토글에 스팸함 확인 안내.

### Apple Sign In - 이메일 숨김
- Apple은 사용자가 "이메일 숨기기" 선택 가능 (랜덤 이메일 발급)
- **처리**: 랜덤 이메일 그대로 저장. 비밀번호 찾기 시 그 랜덤 이메일로 보냄. (Apple이 릴레이)

### 회원 탈퇴
- 탈퇴 = 사용자 데이터 영구 삭제 + 토큰 무효화
- 한 번 더 확인 (다이얼로그)
- 탈퇴 후 같은 이메일로 재가입 가능
- 30일 유예 기간 권장 (실수 방지)
