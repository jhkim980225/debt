# Feature: Statistics

## 목적

사용자에게 자기 패턴을 보여주고 인사이트를 제공. **자기 행동의 효과를 데이터로 확인**할 때 더 큰 동기부여가 됨.

## 우선순위

**Phase 2**

## 핵심 원칙

1. **숫자가 아닌 인사이트**: "당신은 15일에 가장 많이 갚아요" 같은 행동 패턴
2. **비교는 자기 자신과만**: 다른 사용자와 비교 X (CLAUDE.md 원칙 4번)
3. **긍정적 발견에 집중**: "X% 더 갚았어요" O, "Y만큼 부족해요" X

## 사용자 스토리

> 내 상환 데이터를 보면서 잘하고 있는 점을 발견하고, 더 나은 패턴을 찾고 싶다.

## 진입 경로

- 하단 탭바의 "기록" 탭

## 화면 구성

### 헤더
- "통계"

### 섹션 1: 기간 필터
- 칩 3개 (단일 선택):
  1. **최근 6개월** (디폴트)
  2. 올해
  3. 전체
- 선택 시 모든 데이터 갱신

### 섹션 2: 핵심 지표 (그리드 2x1)

#### 카드 1: 총 상환액
- 라벨: "총 상환액"
- 큰 숫자: 기간 내 모든 Payment 합
- 변화: "▲ 지난 기간 대비 X%" (녹색)

#### 카드 2: 절약한 이자
- 라벨: "절약한 이자"
- 큰 숫자: 최소 결제만 했을 때 vs 실제 패턴 비교
- 서브: "최소 결제 대비"

### 섹션 3: 월별 상환액 (바 차트)
- 헤드라인: "월별 상환액"
- 카드 안에 바 차트
- X축: 월
- Y축: 그 달 총 상환액
- 막대 색: 일반 회색-블루, 이번 달 강조 (진한 파랑)
- 막대 위 라벨: "30만", "42만" 같은 만원 단위
- `fl_chart` 사용

### 섹션 4: 빚별 비중 (스택 바 + 리스트)
- 헤드라인: "빚별 비중"
- 가로 스택 바 (전체 빚 잔액 비중)
- 각 빚 컬러
- 아래 리스트:
  - 색 점 + 빚 이름 + 잔액 + %
  - 졸업한 빚도 포함 (다른 색)

### 섹션 5: 발견한 패턴 (인사이트)
- 헤드라인: "발견한 패턴"
- 카드 3개 (인사이트별 색 톤)

#### 인사이트 종류

##### 긍정 (success 톤)
- "상환 속도가 점점 빨라지고 있어요"
  - 조건: 최근 3개월 평균 > 이전 3개월 평균
- "이번 주 X일 연속 갚았어요"
  - 조건: 최근 7일 중 5일 이상 기록
- "목표보다 X원 더 갚는 달이 많아요"
  - 조건: 목표 초과 달 비율 50% 이상

##### 패턴 (warning 톤, 노랑)
- "X일에 가장 많이 갚아요"
  - 조건: 특정 일자에 상환 빈도 높음
- "주말보다 평일에 더 많이 갚아요"
  - 조건: 평일/주말 평균 차이 30% 이상

##### 제안 (info 톤, 파랑)
- "월 X원만 더 갚으면 N개월 빨라져요"
  - 조건: 사용자 평균 + 5만원 시뮬레이션
- "이 빚 먼저 갚으면 이자 X원 절약돼요"
  - 조건: 우선순위가 잘못 설정됐을 때

### 인사이트 우선순위

같은 화면에 너무 많이 보이지 않도록 **최대 3-4개**만:
1. 가장 긍정적인 발견 (사용자 격려)
2. 흥미로운 패턴 (자기 인식)
3. 실행 가능한 제안 (개선)

## 빈 상태

### 데이터 부족 (Payment 5개 미만)
- 일러스트
- "상환 기록이 쌓이면 여기에 그래프와 패턴이 나타나요"
- "1주일만 기록해도 흥미로운 패턴이 보일 거예요"
- 메인 버튼: [+ 상환 기록]

### 1주일 미만
- 기본 차트는 보여주되 인사이트 섹션 비활성

## 인터랙션

### 차트 탭
- 막대 탭하면 그 달의 상세 (몇 회 기록, 어떤 빚)
- 모달 또는 인라인 툴팁

### 인사이트 카드 탭 (선택)
- 더 자세한 설명
- "왜 이런 패턴이 보일까?" 같은 학습 콘텐츠 (Phase 3)

## 카피 디테일

### 톤
- 친구가 데이터 보면서 알려주는 느낌
- "당신은 X합니다" 분석 보고서 톤 X
- "X일에 더 갚는 것 같아요" 부드럽게 O

### 숫자 표현
- 비율: "X% 더", "X% 빨라요"
- 금액: "X만원", "X천만원" (만원 단위가 가독성 좋음)
- 시간: "N개월 빨라져요", "N일 연속"

## Edge Cases

### Payment 0개
- 빈 상태 화면

### Payment 1-4개
- 차트만 표시, 인사이트 숨김

### 모든 빚 졸업
- "졸업한 빚 X개" 통계 추가
- "총 X원을 갚으셨어요" 누적 표시
- 인사이트 대신 회상 메시지

### 데이터 변경 시
- 상환 기록 추가 → 통계 자동 갱신
- 빚 삭제 → 통계 재계산

### 시간대 처리
- 사용자 디바이스 시간대 기준
- 자정 기준으로 일별 그룹

## 분석 이벤트

- `statistics_viewed`
- `statistics_period_changed` (period)
- `statistics_chart_tapped` (chartType, value)
- `statistics_insight_viewed` (insightId)

## 성능

- 데이터 분석은 메모이제이션 (Provider)
- 차트 데이터 변환은 isolate (선택)
- 큰 기간 (전체) 선택 시 로딩 표시
