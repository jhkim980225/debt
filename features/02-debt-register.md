# Feature: Debt Register

## 목적

사용자가 자기 빚을 앱에 등록. **앱의 가치를 사용자가 처음 느끼는 핵심 모멘트**. 마찰을 최대한 줄이는 것이 KPI.

## 우선순위

**Phase 1 (출시 필수)**

## 핵심 원칙

1. **3분 안에 첫 빚 등록 완료** (목표)
2. **모르는 정보는 "잘 모르겠어요"로 회피 가능**
3. **모든 정보는 나중에 수정 가능**
4. **2단계로 분할**: 필수 vs 선택 정보
5. **카테고리 먼저, 숫자 나중**: 입력 마찰 최소화

## 사용자 스토리

> 빚이 있는 사용자로서, 정확한 정보를 다 몰라도 일단 시작할 수 있고, 나중에 채울 수 있다는 안심감 속에서 등록하고 싶다.

## 진입 경로

1. **회원가입 직후** (강제, 건너뛸 수 없음)
2. **대시보드의 [+ 빚 추가] 버튼**
3. **빈 상태 대시보드의 "첫 빚을 등록해볼까요?"**

## 화면 1: 빚 등록 (1/2단계)

### 헤더
- 좌측: × 닫기 (확인 다이얼로그 후)
- 중앙: "새 빚 등록"
- 우측: "1 / 2"

### 섹션 1: 카테고리 선택
- 헤드라인: "어떤 빚인가요?"
- 서브: "카테고리를 골라주세요"
- 그리드 3x2 (6개 옵션)
  - 신용카드 (빨강)
  - 학자금 (주황)
  - 은행대출 (녹색)
  - 지인 (보라)
  - 할부 (핑크)
  - 기타 (회색, "+" 아이콘)
- 각 셀: 아이콘 + 라벨, 선택 시 보더 강조
- **단일 선택 (라디오)**

### 섹션 2: 빚 이름
- 라벨: "빚 이름"
- 텍스트 입력
- 플레이스홀더: 카테고리에 따라 자동
  - 신용카드: "예: 신용카드 A"
  - 학자금: "예: 학자금 2학기"
  - 등
- 도움말 텍스트: "예: 신용카드 A, 학자금 2학기"
- 길이: 1-30자

### 섹션 3: 현재 남은 금액
- 라벨: "현재 남은 금액"
- 숫자 입력 (자동 천단위 콤마)
- 우측 정렬 "원" 표시
- 폰트 크게 (강조)
- 검증: 0보다 큰 정수

### 섹션 4: 연 이자율
- 라벨: "연 이자율"
- 라벨 우측: **"잘 모르겠어요"** 텍스트 버튼
  - 탭 시: 카테고리별 평균값 자동 입력 + 도움말 안내
- 숫자 입력 (소수점 1자리)
- 우측 "%" 표시
- **빠른 선택 칩 3개**:
  - "0% (무이자)"
  - 카테고리별 평균값 (예: 학자금 4.5%)
  - 카테고리별 흔한 값 (예: 신용카드 15%)
- 검증: 0~100

#### "잘 모르겠어요" 처리
탭 시 다이얼로그 또는 인라인 안내:
- "정확한 이자율은 다음에 수정할 수 있어요. 일단 평균값으로 시작할까요?"
- 카테고리별 평균:
  - creditCard: 18.9%
  - studentLoan: 4.5%
  - bankLoan: 6.5%
  - personal: 0%
  - installment: 0% (보통 무이자할부)
  - other: 5%
- 자동 입력 후 사용자가 수정 가능

### 섹션 5: 추가 정보 (펼침)
- `<details>` 형식 토글
- 닫혀있는 게 디폴트
- 펼치면: "처음 빌린 금액, 매월 최소 상환액, 다음 결제일 등"
- **여기엔 실제 입력 필드 없음**. 안내 텍스트만. 실제 입력은 2단계에서.
- 의도: 사용자에게 "더 많은 정보를 나중에 입력할 수 있다"는 신호

### 섹션 6: 안심 메시지
- 정보 카드 (info 톤)
- "ⓘ 정확하지 않아도 괜찮아요. 나중에 언제든 수정할 수 있어요."

### 하단 버튼
- 좌측 (1/3 너비): "취소" (보조)
- 우측 (2/3 너비): "다음 단계 →" (메인)

### 검증
- 카테고리 미선택: "카테고리를 선택해주세요"
- 이름 비어있음: "빚 이름을 입력해주세요"
- 잔액 0 또는 비어있음: "남은 금액을 입력해주세요"
- 이자율 비어있음: 0%로 자동 처리 (강제 아님)

## 화면 2: 빚 등록 (2/2단계)

### 헤더
- 좌측: ← 뒤로 (1단계로)
- 중앙: "새 빚 등록"
- 우측: "2 / 2"

### 진행률 바
- 100% (녹색) 표시
- 시각적으로 "거의 다 왔다" 신호

### 섹션 1: 동기 카피
- 헤드라인: "상환 계획을 세워볼까요?"
- 서브: "건너뛰어도 괜찮아요. 나중에 채울 수 있어요."

### 섹션 2: 매달 최소 상환액
- 라벨: "매달 최소 상환액"
- 숫자 입력 + "원"
- 도움말: "카드사가 요구하는 최소 결제액이에요"
- 선택 입력 (비워도 OK)

### 섹션 3: 매달 갚을 목표 금액
- 라벨: "매달 갚을 목표 금액"
- 숫자 입력 + "원"
- 선택 입력
- **즉시 피드백 카드** (목표가 최소보다 클 때):
  - 녹색 톤 카드
  - "최소보다 X원 더 갚으면 **완납이 N개월 빨라져요**"
  - 계산: `차이금액으로 추가 상환 시 단축되는 개월수`
  - 이 카드가 사용자 동기부여의 핵심

### 섹션 4: 결제일
- 라벨: "결제일"
- 4개 칩 (그리드):
  - "5일", "15일", "25일", "말일"
- 단일 선택
- 선택 시 도움말 갱신: "매달 {N}일에 알려드릴게요"
- 직접 입력 옵션 없음 (Phase 2에서 "기타" 추가 고려)

### 섹션 5: 알림 시점
- 라벨: "언제 알려줄까요?"
- 라디오 옵션 3개 (세로 스택):
  1. **결제일 3일 전** (디폴트, 강조 카드)
     - 서브: "미리 준비할 시간이 있어요"
  2. 결제일 당일
  3. 알림 안 받기

#### 디폴트 선택 이유
- "당일"보다 "3일 전"이 행동 유도에 효과적
- 돈을 마련할 시간을 제공
- 단, 사용자 선택권 존중 ("안 받기" 옵션 필수)

### 섹션 6: 미리보기 카드
- 헤드라인: "이렇게 등록돼요"
- 카드 형태로 입력값 요약:
  - 빚 이름 + 카테고리 색 점
  - 현재 잔액
  - 이자율 + 결제일 + 목표 금액
  - 구분선
  - **예상 완납**: "약 N개월 후"
- 사용자가 한 번 더 확인하는 용도
- 입력값에 따라 실시간 갱신

### 하단 버튼
- 좌측 (1/3): "건너뛰기" (보조, 회색)
- 우측 (2/3): "등록 완료" (메인)

### "건너뛰기" 동작
- 2단계 정보 모두 비운 채 등록 완료
- 빚은 정상 생성됨

## 화면 3: 등록 완료 (축하)

### 디자인 의도
빚 등록은 심리적으로 무거운 행동. 끝낸 직후 **"잘하고 있다"** 신호를 줘야 다음 행동으로 이어짐.

### 레이아웃
- 상단: 컨페티 SVG (작은 점/사각형 흩뿌림)
- 중앙 큰 원 (녹색 배경 + 흰 체크)
- 헤드라인: "첫 걸음을 떼셨어요!"
- 서브: "빚을 정확히 마주하는 게 가장 어려운 일이에요. 이미 큰 산을 넘었어요."

### 새 배지 카드
- 노랑 배경 카드
- 좌측: 별 아이콘 (배지 비주얼)
- 우측 텍스트:
  - 작게: "새 배지 획득"
  - 크게: "첫 걸음"
- 의도: 게이미피케이션 트리거 + "또 모으고 싶다"

### 등록 정보 요약 카드
- 등록한 빚 금액 표시
- "매달 N원씩 갚으면"
- "**YYYY년 MM월에 졸업해요**" (구체적 날짜)
- 의도: 막연한 "언젠가"가 아닌 진짜 날짜 → 동기부여 강력

### 다음 액션 카드 2개
1. **다른 빚도 등록하기**
   - 아이콘: + (파란 박스)
   - 카피: "전체 그림이 보여야 계획이 정확해져요"
   - 의도: 빚 여러 개 있는 사용자가 첫 개만 등록하고 끝내지 않게 유도
2. **대시보드 보러 가기**
   - 아이콘: 그리드 (녹색 박스)
   - 카피: "전체 진행 상황을 한눈에"

### 하단 메인 버튼
- "대시보드로 가기"

## 데이터 흐름

### 1단계 → 2단계
- 1단계 입력값을 임시 상태로 보관 (Riverpod)
- 2단계로 이동 (push)
- 뒤로가기 시 1단계 입력값 유지

### 2단계 → 등록 완료
1. 임시 상태의 모든 입력 합쳐서 `Debt` 엔티티 생성
2. Hive에 저장
3. 우선순위 자동 재계산 (전체 빚 대상)
4. 첫 빚이면 `firstStep` 배지 자동 획득
5. 축하 화면 진입

### 등록 후 동작
- 우선순위 빚 결정 (사용자 전략 기반)
- 대시보드 진입 시 새 빚이 목록에 표시됨

## 입력 검증 정책

### 1단계
- **카테고리**: 필수
- **이름**: 필수, 1-30자
- **잔액**: 필수, 0보다 큰 정수
- **이자율**: 선택 (디폴트 0)

### 2단계
- 모두 선택 (건너뛰기 가능)
- 입력 시:
  - 최소/목표 상환액: 0보다 큰 정수
  - 결제일: 1-31 또는 -1 (말일)
  - 알림 시점: enum

### 숫자 입력 UX
- 키보드: 숫자 키패드
- 자동 천단위 콤마 (`1,000,000`)
- 한국어 단위 보조 표시 (선택, Phase 2): "100만원"

## 카피 디테일

### 톤
- 부드럽고 격려하는
- "입력하세요" 명령형 X
- "골라주세요", "갚을까요?" 권유형 O

### 모르는 사용자 배려
- "잘 모르겠어요" 적극 노출
- "정확하지 않아도 괜찮아요"
- "나중에 수정할 수 있어요"

## Edge Cases

### 도중에 닫기 시도
- × 버튼 누르면 다이얼로그
- "지금까지 입력한 내용이 사라져요. 정말 닫으시겠어요?"
- "닫기" / "계속 입력하기"

### 같은 이름의 빚 중복
- 허용. 사용자가 "신용카드 A", "신용카드 B" 식으로 관리 가능
- 단, 완전히 같은 이름이면 자동으로 "(2)" 접미사

### 매우 큰 금액 입력
- 최대: 999,999,999,999원 (1조 미만)
- 그 이상은 입력 안 됨

### 음수 입력 시도
- 키패드에서 - 입력 불가능

### 0원 빚
- 거부. "남은 금액을 입력해주세요"
- 0이면 그건 빚이 아니라 졸업한 것이라 별도 화면 필요

### 첫 등록인지 N번째 등록인지
- 첫 등록: 축하 화면 풀버전
- 두 번째 이상: 축하 화면 간소화 (배지 없으면 그냥 토스트)
