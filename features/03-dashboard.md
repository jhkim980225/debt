# Feature: Dashboard

## 목적

사용자가 매일 가장 자주 보는 화면. **앱을 열었을 때 가장 알고 싶은 정보를 한 화면에**. 동기 부여 + 다음 행동 유도.

## 우선순위

**Phase 1 (출시 필수)**

## 핵심 원칙

1. **3초 안에 핵심 정보 파악 가능**: 총 빚, 진행률, 다음 할 일
2. **개인화된 환영**: "안녕하세요, [닉네임]님" + 동기부여 카피
3. **우선순위 빚 강조**: 사용자가 어디에 집중해야 하는지 명확히
4. **실행 가능한 다음 액션**: [상환 기록] 버튼 항상 노출

## 사용자 스토리

> 매일 앱을 켤 때마다, 내 빚 현황을 한눈에 파악하고 오늘 뭘 해야 할지 바로 알고 싶다.

## 진입 경로

1. **앱 첫 시작**: 자동 로그인 후 자동 진입
2. **빚 등록 완료 후**
3. **하단 탭바**의 "홈" 탭

## 화면 구성

### 섹션 1: 인사 헤더
- 좌측: "안녕하세요, [닉네임]님"
- 우측: 오늘 날짜 (예: "5월 1일")
- 아래 큰 텍스트: 동기부여 카피 (매일 다름)

#### 카피 풀
랜덤 또는 상황 기반:
- "오늘도 한 걸음씩, 천천히 가요"
- "어제보다 가까워지고 있어요"
- "함께 가요, 멈추지 말고"
- "꾸준함이 가장 빠른 길이에요"
- 등 20개 이상

#### 상황 기반 카피
- 연속 7일 이상: "{N}일째 함께하고 있어요. 멋져요!"
- 결제일 임박: "신용카드 A 결제일이 3일 남았어요"
- 새로운 달 첫날: "5월의 첫 걸음을 떼볼까요?"
- 빚 졸업 직후: "{빚이름} 졸업 축하해요! 다음 목표로!"

### 섹션 2: 총 빚 + 진행률 (메인 카드)
- 작은 라벨: "남은 총 빚"
- **큰 숫자**: 총 잔액 (예: "12,450,000원", `displayAmount` 스타일)
- 변화 표시:
  - 녹색 ▼ + 이번 달 갚은 금액
  - 또는 "이번 달 첫 상환을 시작해보세요"

#### 진행률 바
- 라벨 좌측: "전체 진행률"
- 라벨 우측: "%" (강조)
- 진행률 바 (녹색)
- 아래 작은 텍스트: "시작: {초기금액}원 · 갚은 금액: {갚은금액}원"

#### 진행률 계산
- `initialAmount`이 있는 빚만 합산해서 계산
- 모두 없으면 진행률 표시 안 함, "갚을수록 진행률이 채워져요" 메시지

### 섹션 3: 연속 기록 카드 (조건부)
- 연속 1일 이상일 때만 표시
- 파란 톤 카드
- 좌측: 별 아이콘
- 우측 텍스트:
  - "**{N}일 연속 상환 중**"
  - "매일 조금씩 갚고 있어요. 이 페이스면 N개월 안에 {빚이름} 졸업이에요!"

#### 변형
- 7일 미만: 단순 격려
- 7일 이상: 구체적 예측 ("이 페이스면 N개월 후 졸업")
- 30일 이상: 특별 강조 (배지 보여주기)
- 위험 (오늘 안 갚으면 끊김): 경고 톤 변경

### 섹션 4: 내 빚 목록
- 헤더: "내 빚 목록" + 우측에 개수 표시
- 카드 리스트 (상하 정렬)

#### 정렬 순서
사용자 전략 기반:
- **눈덩이 (Snowball)**: `currentBalance` 오름차순
- **눈사태 (Avalanche)**: `interestRate` 내림차순
- 졸업한 빚은 하단 또는 숨김 (사용자 선택)

#### 각 빚 카드
- 상단 좌측: 카테고리 색 점 + 빚 이름
- "우선순위" 배지 (1번째 빚에만)
- 상단 우측: 잔액 (작게)
- 진행률 바 (가는, 카테고리 색)
- 하단: "이자율 X%" / "X% 완료"
- **탭하면 빚 상세 화면으로**

### 섹션 5: 액션 버튼
- 좌측 (1/2): [+ 상환 기록] (메인, 검정 배경)
- 우측 (1/2): [시뮬레이션] (보조, 보더만)

### 섹션 6: 하단 탭바
- 4개 탭: 홈 / 기록 / 배지 / 설정
- 또는 5개 (커뮤니티 추가)
- 활성 탭: `textPrimary` 색 + 굵게
- 비활성: `textTertiary`

## 빈 상태 (No Debts)

빚이 0개일 때 (신규 회원이지만 등록 안 한 경우 또는 모두 졸업).

### 모든 빚 졸업 시 (특별 화면)
- 큰 컨페티
- "축하해요! 모든 빚을 갚으셨어요!"
- 졸업한 빚 목록 (회상)
- "새로운 목표 세우기" or "여정 공유하기"
- 별도 디자인 필요 (Phase 2)

### 빚 등록 안 한 경우
- 일러스트 (작은)
- 헤드라인: "첫 빚을 등록해볼까요?"
- 서브: "정확히 마주하면 갚는 길이 보여요"
- 메인 버튼: "빚 등록하기"

## 인터랙션

### 새로고침
- 풀투리프레시 (Pull to refresh) 지원
- 데이터 갱신 + 진행률 재계산

### 빚 카드 탭
- 빚 상세 화면으로 이동 (`/debt/{id}`)

### [+ 상환 기록] 버튼
- 모달로 상환 기록 화면 열림
- 우선순위 빚 자동 선택됨

### [시뮬레이션] 버튼
- 시뮬레이션 화면으로 이동

### 빚 카드 길게 누르기 (선택)
- 컨텍스트 메뉴: 수정 / 삭제 / 졸업 처리

## 데이터 흐름

### 진입 시
1. Hive에서 사용자 정보 로드
2. Hive에서 빚 목록 로드 (졸업 안 한 것 우선)
3. 정렬 (전략 기반)
4. 진행률 계산
5. 연속 기록 일수 계산 (오늘 vs 어제 Payment 존재 여부)
6. 동기부여 카피 결정 (상황 기반)

### 실시간 갱신
- 상환 기록 후 자동 갱신 (Provider 통해)
- 빚 추가/수정 후 자동 갱신
- 자정 지나면 연속 기록 재계산

## 성능 가이드

### 캐싱
- 진행률 계산 결과는 메모이제이션
- 빚 변경 시에만 재계산
- `Provider.family` 또는 `select` 활용

### 빚 개수 많을 때
- 10개 이상이면 일부만 표시 + "더 보기"
- 30개 이상은 거의 없을 것이지만 가상 스크롤 고려

## 카피 디테일

### 동기부여 카피 (상단 큰 텍스트)
- 길이: 한 줄, 최대 20자
- 톤: 따뜻함, 친구처럼
- 압박 X: "더 빨리 갚으세요"
- 격려 O: "꾸준함이 답이에요"

### 진행률 표현
- "X% 완료" (긍정적)
- "X% 남음" (X) 부정적이라 안 씀

### 금액 표현
- 천단위 콤마: `12,450,000원`
- 변화량: `▼ 850,000원` (녹색), `▲` 안 씀 (빚이 늘어나는 건 좋지 않으니)

## Edge Cases

### 빚이 1개일 때
- 우선순위 배지는 표시 안 함 (혼자라 의미 없음)
- 또는 "현재 갚고 있는 빚" 표시

### 빚을 모두 졸업한 직후 첫 진입
- 특별 축하 화면 (메인 대시보드 대신)
- 사용자가 닫으면 평소 빈 상태로

### 0원 짜리 빚 (졸업 직후)
- 자동으로 "졸업" 처리 (`isPaidOff = true`)
- 메인 목록에서 제외, 졸업한 빚 섹션 별도

### 이자율 0%인 빚
- 정상 표시. "이자율 0%"

### 진행률 계산 불가 (initialAmount 없음)
- 진행률 바 안 보이거나 placeholder
- 갚을수록 누적해서 보여주기 (월별 갚은 금액 합)

### 연속 기록 끊긴 직후
- "연속 기록이 리셋됐어요. 오늘부터 다시 시작!"
- 너무 비난조면 안 됨

### 오늘 결제일인 빚
- 해당 빚 카드에 "오늘 결제일" 라벨 자동 추가
- 약간 강조
