# Feature: Onboarding

## 목적

처음 앱을 켠 사용자에게 앱의 가치를 전달하고 자연스럽게 회원가입으로 유도. **빚 앱은 첫인상이 모든 것**. "감시당하는 느낌"이 아닌 "내 편이 생겼다"는 느낌을 줘야 함.

## 우선순위

Phase 1 (출시 필수). 단, MVP 단계에서는 슬라이드 1개만으로 시작 가능.

## 사용자 스토리

> 처음 빚 관리 앱을 깐 사용자로서, 이 앱이 나를 어떻게 도와줄지 빠르게 이해하고 부담 없이 시작하고 싶다.

## 화면 구성

### Onboarding Slides (4단계)

총 4개 슬라이드. 각 슬라이드는 **일러스트 + 짧은 카피 + 다음/건너뛰기 버튼**으로 구성.

#### Slide 1: 가치 제안
- **일러스트**: 빨간 점("지금")에서 초록 체크("자유")로 가는 점선 경로 (베이지 원 안에)
- **헤드라인**: "빚, 혼자 갚지 마세요"
- **서브 카피**: "함께 계획하고, 매일 응원받으며, 한 걸음씩 자유에 가까워져요."

#### Slide 2: 핵심 기능 1
- **일러스트**: 여러 빚을 카드로 표현, 진행률 바
- **헤드라인**: "한눈에 보이는 내 빚"
- **서브 카피**: "전체 그림이 보이면 막막함이 사라져요. 진행률, 예상 완납일까지 한 화면에."

#### Slide 3: 핵심 기능 2
- **일러스트**: 캘린더 + 연속 기록 표시
- **헤드라인**: "매일 작은 진전"
- **서브 카피**: "꾸준함이 가장 큰 힘이에요. 매일의 한 걸음을 응원해줄게요."

#### Slide 4: 핵심 기능 3
- **일러스트**: 사람 여러 명 실루엣
- **헤드라인**: "혼자가 아니에요"
- **서브 카피**: "비슷한 여정에 있는 사람들과 정보를 나누고 응원받아요."

### 공통 요소
- **상단**: 진행률 인디케이터 (4개 점, 현재 슬라이드 강조)
- **상단 우측**: "건너뛰기" 텍스트 버튼 (1, 2, 3 슬라이드에만)
- **하단**: 메인 버튼
  - 슬라이드 1-3: "다음"
  - 슬라이드 4: "시작하기"
- **하단 보조**: "이미 계정이 있어요" → 로그인 화면

## 인터랙션

### 슬라이드 전환
- 좌우 스와이프로 이동 (PageView)
- 점 인디케이터 탭으로도 이동
- "다음" 버튼 탭으로 이동
- 마지막 슬라이드에서 "시작하기" → 회원가입 화면

### "건너뛰기"
- 모든 슬라이드 건너뛰고 바로 회원가입 화면으로

### 첫 진입 판별
- `SharedPreferences`에 `onboardingCompleted` 플래그 저장
- 한 번 완료하면 다시 안 보여줌 (단, 설정에서 "다시 보기" 옵션 가능 - Phase 4)

## 카피 디테일

### 톤
- 따뜻하지만 진지함 (CLAUDE.md 원칙 1번)
- 지시형 X ("빚을 등록하세요")
- 동반자 톤 O ("함께 시작해요")
- 부담 X ("3분만에" 같은 시간 압박 카피 X)

### 헤드라인 길이
- 한 줄, 최대 12자 권장
- 폰트 크기: `displayLarge` (24)

### 서브 카피
- 2줄까지 OK
- 폰트 크기: `bodyMedium` (13)
- 색상: `textSecondary`

## Edge Cases

### 도중에 앱 종료
- 진행 상태 저장 안 함. 다시 켜면 슬라이드 1부터.
- 단, "건너뛰기"를 눌렀거나 끝까지 본 경우는 `onboardingCompleted = true`

### 이미 회원가입한 사용자
- 자동 로그인되면 온보딩 안 보여주고 바로 대시보드.
- 단, 로그아웃 후 재로그인 시에도 온보딩 안 보여줌 (이미 가입자니까).

### 일러스트 로딩 실패
- 단순한 이모지나 아이콘으로 fallback (앱 멈추지 않음)

## 분석 (Analytics)

추적해야 할 이벤트:
- `onboarding_started` (앱 첫 실행)
- `onboarding_slide_viewed` (각 슬라이드 노출, slideIndex 포함)
- `onboarding_skipped` (건너뛰기 클릭 시점, slideIndex 포함)
- `onboarding_completed` (마지막 슬라이드까지)
- `onboarding_to_signup` ("시작하기" 클릭)
